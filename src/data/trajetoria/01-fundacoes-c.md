<!-- NARRATIVA -->
Tudo começou em 2022, quando ingressei no curso de Ciência da Computação na Universidade Federal de Goiás. Na disciplina de Introdução à Programação, tive meu primeiro contato com a linguagem C — e foi ali que entendi o que realmente significa programar.

C é uma linguagem que não te protege: ponteiros, alocação de memória, gerenciamento manual de recursos. Exatamente por isso considero essa base uma das mais sólidas que um desenvolvedor pode ter. Você aprende o porquê das coisas, não apenas o como.

<!-- TECNICO -->
A disciplina de Introdução à Programação na UFG utilizava C como linguagem base. Trabalhar diretamente com ponteiros, alocação dinâmica (`malloc`, `free`) e estruturas de memória construiu uma compreensão profunda do que acontece por baixo das abstrações de linguagens de alto nível — fundamento que impacta diretamente como raciocino sobre performance e gerenciamento de recursos até hoje.

<!-- NARRATIVA_EN -->
It all started in 2022, when I enrolled in the Computer Science program at the Federal University of Goiás. In the Introduction to Programming course, I had my first contact with C — and that's where I understood what programming really means.

C is a language that doesn't protect you: pointers, memory allocation, manual resource management. That's precisely why I consider this foundation one of the strongest a developer can have. You learn the why of things, not just the how.

<!-- TECNICO_EN -->
The Introduction to Programming course at UFG used C as its base language. Working directly with pointers, dynamic allocation (`malloc`, `free`) and memory structures built a deep understanding of what happens beneath the abstractions of high-level languages — a foundation that directly shapes how I reason about performance and resource management to this day.

Desafio focado em CRUD completo com Spring Data JPA. Foi um dos primeiros projetos em que consegui transformar o estudo do ecossistema Spring em algo concreto e funcional.

Mais do que o resultado final, ele serviu para consolidar confiança: criar endpoints, persistir dados, organizar responsabilidades e ver a aplicação funcionando ponta a ponta.

CRUD com Spring Boot, Spring Data JPA e H2. Estrutura em camadas (Controller → Service → Repository), modelagem simples de entidades e foco em organização de código desde o primeiro commit. Projeto importante para fixar o fluxo básico de uma API REST integrada a banco.

<!-- NARRATIVA -->
Mesmo me identificando mais com back-end, eu sentia que os projetos ficavam incompletos sem interface. O MediasSite foi uma forma de fechar esse ciclo na MediasAPI e entender melhor como a experiência do usuário conversa com a lógica do sistema.

Foi uma etapa de exploração controlada no front-end: menos sobre dominar tudo e mais sobre aprender o suficiente para construir uma interface coerente para um produto que eu já conhecia profundamente.

<!-- TECNICO -->
SPA em Vue.js + Vite consumindo a REST API da MediasAPI. A aplicação cobriu autenticação, organização de fluxo de telas, consumo de endpoints e tratamento do estado necessário para projeções e notas. O projeto consolidou integração prática entre front-end e uma API já existente.

<!-- NARRATIVA_EN -->
Even though I identify more with back-end, I felt the projects were incomplete without an interface. MediasSite was a way to close that loop for MediasAPI and better understand how user experience connects with system logic.

<!-- NARRATIVA -->
No segundo período, a disciplina de Programação Orientada a Objetos me apresentou o Java — e algo clicou. Decidi ir além do conteúdo da faculdade e comecei a estudar por conta própria, conciliando com o curso.

Estudei a fundo os fundamentos da linguagem: herança, polimorfismo, encapsulamento, interfaces. Depois fui além — generics, lambdas, streams, a API de coleções. Não queria apenas usar Java, queria entender como ele funcionava.

Em paralelo, as disciplinas de Estrutura de Dados e Algoritmos 1 e 2 trouxeram projetos em equipe onde aplicamos esses conceitos na prática — incluindo implementações como tabelas hash e outros projetos que ficaram registrados, e muitos outros de treino que nunca chegaram a um repositório.

<!-- TECNICO -->
O estudo autodidata de Java cobriu desde os fundamentos de OOP até recursos mais avançados da linguagem: generics, lambdas, streams, a Collections API e o modelo de memória da JVM. As disciplinas de EDA 1 e 2 na UFG complementaram com teoria e prática de estruturas de dados clássicas — listas, árvores, grafos, tabelas hash — implementadas do zero em projetos de equipe com metodologia ágil (Scrum).

<!-- NARRATIVA_EN -->
In the second semester, the Object-Oriented Programming course introduced me to Java — and something clicked. I decided to go beyond the coursework and started studying on my own, alongside the degree.

I went deep into the language fundamentals: inheritance, polymorphism, encapsulation, interfaces. Then further — generics, lambdas, streams, the Collections API. I didn't just want to use Java, I wanted to understand how it worked.

In parallel, the Data Structures and Algorithms 1 and 2 courses brought team projects where we applied these concepts in practice — including implementations like hash tables and other projects that made it to a repository, and many more practice ones that never did.

<!-- TECNICO_EN -->
Self-taught Java study covered everything from OOP fundamentals to more advanced language features: generics, lambdas, streams, the Collections API and the JVM memory model. The EDA 1 and 2 courses at UFG complemented this with theory and practice of classic data structures — lists, trees, graphs, hash tables — implemented from scratch in team projects using agile methodology (Scrum).

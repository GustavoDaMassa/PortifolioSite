<!-- NARRATIVA -->
Depois de construir projetos mais robustos no back-end, percebi que precisava mostrá-los melhor. O portfólio em React nasceu dessa necessidade de apresentação: organizar a trajetória, dar contexto aos projetos e transformar trabalho técnico em narrativa visível.

Foi também uma forma de voltar ao front-end com mais intenção. Em vez de estudar componentes soltos, eu tinha um produto com identidade própria, conteúdo real e um objetivo claro.

<!-- TECNICO -->
Portfólio desenvolvido em React com Vite, CSS Modules e Framer Motion. Estrutura orientada a páginas, suporte a internacionalização PT/EN e foco em performance, organização visual e manutenção simples. Esse projeto passou a funcionar como vitrine técnica central da trajetória.

<!-- NARRATIVA_EN -->
After building stronger back-end projects, I realized I needed a better way to present them. The React portfolio came from that need: organize the journey, give context to the projects and turn technical work into a visible narrative.

It was also a way to return to front-end with more intention. Instead of studying isolated components, I had a product with its own identity, real content and a clear goal.

<!-- TECNICO_EN -->
Portfolio built with React, Vite, CSS Modules and Framer Motion. It uses a page-oriented structure, PT/EN internationalization support and focuses on performance, visual organization and simple maintenance. This project became the central technical showcase of the journey.

<!-- NARRATIVA -->
Foi nesse período que o back-end deixou de ser apenas teoria e começou a parecer trabalho real. Ao entrar no ecossistema Spring, comecei a enxergar como APIs REST são estruturadas no dia a dia: receber requisições, validar dados, organizar regras de negócio e persistir informações em banco.

Esse estudo virou um contexto importante para tudo que veio depois. Antes dos projetos maiores, precisei entender o fluxo básico de uma aplicação de verdade — controller, service, repository, entidades, DTOs e integração com banco. Foi a fase em que o back-end passou a fazer sentido como profissão, não só como matéria de faculdade.

<!-- TECNICO -->
Estudo focado no ecossistema Spring para entender a construção de APIs REST em Java de forma prática. Consolidei conceitos como arquitetura em camadas, ciclo completo de requisição HTTP, serialização JSON, validação de entrada, integração com bancos relacionais via JPA e organização de regras de negócio dentro da camada de serviço. Esse período serviu como base técnica para os projetos que vieram em seguida.

This was the phase when back-end started making sense as a profession, not just as a university subject.

Focused study on the Spring ecosystem to understand how to build REST APIs in Java in a practical way. I consolidated concepts such as layered architecture, the full HTTP request lifecycle, JSON serialization, input validation, relational database integration through JPA and business-rule organization inside the service layer. This period served as the technical foundation for the projects that followed.

Houve um breve período em que parei para olhar com mais atenção para o front-end. Eu ainda não sabia exatamente qual caminho seguir, então precisava entender o básico antes de decidir com consciência.

Não houve projetos relevantes nessa etapa. O objetivo era ganhar repertório: entender como a interface funciona, como a web é montada e o que eu realmente gostava ou não nesse lado do desenvolvimento.

<!-- TECNICO -->
Estudo introdutório de HTML, CSS e JavaScript voltado à base da web: estruturação semântica, estilização, manipulação do DOM, eventos e noções de responsividade. Foi um período curto de exploração técnica, mais focado em entendimento do ecossistema do que em entrega de aplicações completas.

There was a brief period when I stopped to look more carefully at front-end development. I still did not know exactly which path to follow, so I needed to understand the basics before making that choice consciously.

Introductory study of HTML, CSS and JavaScript focused on web fundamentals: semantic structure, styling, DOM manipulation, events and basic responsiveness. It was a short period of technical exploration, more centered on understanding the ecosystem than on delivering complete applications.
